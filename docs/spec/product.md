# 推し活カウントダウン 方針

## 誰のためのアプリか

推し活をしている人。推しのライブ・誕生日・発売日・配信など、楽しみな日を待っている人。

## 何がうれしいか

- 楽しみな日まで「あと何日」かを、ひと目で数えられる
- 予定もカウントダウンも、推し色で彩られる
- ホーム画面・ロック画面のウィジェットや通知で、アプリを開かなくても残りが分かる
- アカウントの登録がいらず、データは端末の中だけ

## 原則

新しい機能を決めるときも、この原則に従う。ぶつかるときは、原則を変えるかどうかから決める。

1. **通信しない**: 推し・写真・予定は端末の外に送らない。解析・自前のサーバーも使わない。課金はストアの仕組みだけで行う
2. **推し色が主役**: テーマや見た目を変えても、[推し色](design/oshi-colors.md)の値と役割は変えない
3. **広告を入れない**: 広告の枠も置かない
4. **数える機能は無料**: 今ある無料の機能（数える・ウィジェット・通知・ロック画面・当日の表示・シェア）を有料に移さない

## 作らないもの

- 広告
- 検索
- カレンダーのタブ
- アカウント・端末をまたぐ同期
- 予定ごとの通知の設定（通知はアプリ全体で 1 つの設定にする）

## お金の取り方

有料の機能 [推し活カウントダウン Plus](features/14-plus.md) で、推しの写真で見た目を飾る機能を解放する。
数える機能は無料のまま、見た目の楽しみを有料にする。テーマや飾りを定期的に足して、払い続ける価値を保つ。

## うまくいったかの見方

解析を入れないので、ストアで見られる数字（ダウンロード・評価・Plus の購入と継続）とレビューで確かめる。

## 全体の方針

Shariverse のアプリに共通の決まりは [Shariverse の方針](shariverse.md)。
