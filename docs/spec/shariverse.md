# Shariverse の方針

Shariverse のどのアプリにも効く決まり。アプリごとの方針は、各アプリの `product.md`。

## 届け方

- iOS と Android の両方に届ける。機能・文言・規則・配色は両方でそろえる
- 部品と操作感は、それぞれの OS の標準に従う。片方の OS の画面をもう片方にそのまま写さない
- 小さく作って出し、使いながら手を入れ続ける

## 名前

- アプリの名前は、決めた名前をそのまま使う。短くしたり言い換えたりしない（意味を担う語を落とすと、意味が変わる）
- ホーム画面の表示名などに収まらないときだけ短い名前を決め、そのアプリの OS ごとの決定に書く

## だれでも使えるように

- 文字は、地に対して 4.5:1 以上のコントラストにする
- ライトとダークの両方の外観に対応する
- 端末の文字の大きさの設定に追従する。追従させないもの（装飾として描く文字など）は、そのアプリの仕様に書く
- 押せる範囲は、iOS は 44×44pt、Android は 48×48dp 以上（見た目を変えずに、押せる範囲だけ広げてもよい）
- 読み上げで、要素の名前と状態が分かるようにする。装飾は読み上げない
- 動きを減らす設定のときは、アニメーションを止めるか最小限にする
- 光の点滅は 1 秒に 3 回未満にする
