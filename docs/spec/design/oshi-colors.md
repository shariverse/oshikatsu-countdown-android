# 推し色

推しごとに 12 色から 1 つ選ぶ。推し色が主役で、テーマを変えても色の値と役割は変えない。

## 色

塗りの上に白い文字を置くので、どの色も白に対して 4.5:1 以上になる濃さにしてある。

| キー | 名前 | 値 |
|---|---|---|
| `pink` | ピンク | `#C8326A` |
| `red` | レッド | `#D0352B` |
| `orange` | オレンジ | `#B45A0E` |
| `yellow` | イエロー | `#8A6D00` |
| `green` | グリーン | `#1A7A50` |
| `mint` | ミント | `#0E7C86` |
| `blue` | ブルー | `#2F6FD6` |
| `navy` | ネイビー | `#3B4BB8` |
| `purple` | パープル | `#7A4BD0` |
| `lavender` | ラベンダー | `#A23FB0` |
| `brown` | ブラウン | `#6B5B4B` |
| `black` | ブラック | `#3A3842` |

既定はピンク。保存するときもこのキーで持つ（知らないキーを読んだらピンクとして扱う）。

## 役割

- 先頭の予定のカード・ウィジェット・ライブアクティビティの塗り（上に白い文字）
- 写真が無いときの模様の色
- 残り日数の文字
- 推しの印（推しカウントの丸など）

## 地の上の文字に使うとき

暗い推し色でも地に対して 4.5:1 を保つよう、地に合わせて寄せる。

- ダーク: 白に 45% 寄せる
- ライト: そのまま
