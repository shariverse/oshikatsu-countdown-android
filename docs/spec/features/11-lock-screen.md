# ロック画面のカウントダウン

> [!NOTE]
> Android 版では、まだ作っていない（予定）。

[カウントダウンのウィジェット](10-home-widgets.md#カウントダウン)と同じく、選んだ予定 1 件。ロック画面は端末が単色で描くので、推し色の塗りとテーマの装飾は使わない。押すとアプリで予定の詳細を開く。

Android の端末のどこに置くか（ロック画面の仕組みが端末によって違うため）は、Android 版を作るときに決める。下の形（丸・長方形・1 行）と文言、端末が単色で描く前提は iOS 版のもの。

- 丸: 残り日数の数字と「日」、[進み具合](../rules.md)の輪（詳細の進み具合と同じ）。当日は「今日！」、終わった予定は「N 日前」
- 長方形: 推しの名前（推しなしの予定は種類）・タイトル・「あと N 日」（当日は「今日！」、終わった予定は「N 日前」）
- 1 行: 「あと N 日 · タイトル」（当日は「今日！ · タイトル」、終わった予定は「N 日前 · タイトル」。端末が後ろを切り詰めるので、残り日数を先に出す）
- 輪が進むのは、ウィジェットを数え直す・描き直すとき（[ホーム画面ウィジェット](10-home-widgets.md#共通)と同じ）で、その間は止まっている
- 読み上げは、どの形でも「推しの名前、タイトル、あと N 日」
- 予定を選んでいない・見つからない・読み込めないとき: 長方形と 1 行は、カウントダウンのウィジェットの見出しと同じ文言（「予定を選んでください」「予定が見つかりません」「データを読み込めませんでした」）だけを出す。丸は文字が収まらないので、注意の印が付いた予定の記号だけを出し、読み上げで同じ文言を伝える。押すとアプリを開く（ホームのタブに切り替えるだけ）
