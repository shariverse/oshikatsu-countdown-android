# 推しの一覧と登録・編集

## 一覧

[推しの並べ替え](15-oshi-order.md)で決めた順（並べ替えるまでは登録した順）に、アバター・名前・予定の件数（「予定 3 件」）。押すと編集、「推しを登録」で登録。

- 「推しを登録」は右下に置く
- 推しが 1 人もいないときは「推しを登録しよう」「名前と推し色を登録すると、予定やカウントダウンが推し色になります。」と「推しを登録」

## アバター

- 写真があれば丸く出す。写真が無ければ、推し色の丸に白い頭文字（名前の見た目の 1 文字）
- 頭文字の大きさは丸の大きさに合わせ、端末の文字の大きさの設定には追従させない（丸からはみ出さないため）
- 名前を横に並べて出すので、アバターは読み上げない

## 登録・編集

見出しは「推しを登録」「推しを編集」。

- 写真（写真を選ぶ・変える・外す）。選んだら[写真の調整](07-photo-crop.md)の画面で丸の範囲を決める
- 名前（「推しの名前」。必須。20 文字まで）
- 推し色（「推し色（メンバーカラー）」。[12 色](../design/oshi-colors.md)から 1 つ）
- 「写真と推し色はこの端末の中だけに保存されます」

## 削除

編集のときだけ「推しを削除」を置く。確認のダイアログ「「（名前）」を削除しますか？」に、一緒に消える予定の件数を出す（「この推しの予定 3 件も削除されます。元に戻せません。」。無ければ「元に戻せません。」）。推しと、結び付いた予定と、写真を消す。

## 写真の取り込み

- 選んだ写真は、調整で決めた正方形に切り抜き、一辺 1440px 以下の JPEG にしてアプリの中に取り込む（[写真の調整](07-photo-crop.md#取り込み)）
- 写真の調整はまだ作っていないので、今は選んだ写真を長辺 1440px 以下の JPEG（画質 88）に縮めて取り込む
- 差し替え・外す・推しの削除で、前の写真を消す
- 保存のときに写真を取り込めなかったら、前の写真のまま（登録では写真なしで）保存する。推しの保存に失敗したら、取り込んだ写真を消し、前の写真は残す
- 写真を選ぶのに、写真ライブラリ全体の権限は求めない（OS の写真の選択画面を使う）
