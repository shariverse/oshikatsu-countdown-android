# 推しの一覧と登録・編集

## 一覧

登録した順に、アバター・名前・予定の件数。押すと編集、「推しを登録」で登録。

## 登録・編集

- 写真（写真を選ぶ・変える・外す）。選んだら[写真の調整](07-photo-crop.md)の画面で丸の範囲を決める
- 名前（必須。20 文字まで）
- 推し色（[12 色](../design/oshi-colors.md)から 1 つ）
- 「写真と推し色はこの端末の中だけに保存されます」

## 削除

編集のときだけ。確認のダイアログに、一緒に消える予定の件数を出す。推しと、結び付いた予定と、写真を消す。

## 写真の取り込み

- 選んだ写真は、調整で決めた正方形に切り抜き、一辺 1440px 以下の JPEG にしてアプリの中に取り込む（[写真の調整](07-photo-crop.md#取り込み)）
- 写真の調整はまだ作っていないので、今は選んだ写真を長辺 1440px 以下の JPEG に縮めて取り込む
- 差し替え・外す・推しの削除で、前の写真を消す
- 写真を選ぶのに、写真ライブラリ全体の権限は求めない（OS の写真の選択画面を使う）
