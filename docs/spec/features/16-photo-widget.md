# 推しの写真ウィジェット

> [!NOTE]
> Android 版では、まだ作っていない（予定）。

[推し活カウントダウン Plus](14-plus.md) の機能。ホーム画面ウィジェットの新しい種類で、選んだ予定の推しの写真を背景に、残り日数を出す。
[カウントダウンと推しカウント](10-home-widgets.md)は無料のまま変えない。

Android での大きさ・写真の読み込み方・Plus が使えるかの確かめ方・Plus でないときに押して開く画面は、Android 版を作るときに決める。下の中身と規則は iOS 版のもの。

- 一覧に出す名前は「推しの写真」、説明は「推しの写真を背景に、選んだ予定まであと何日かを表示します」
- 予定は[カウントダウン](10-home-widgets.md#カウントダウン)と同じように選ぶ

## 中身

| 大きさ | 中身 |
|---|---|
| 小 | 写真を全面に敷き、下に残り日数とタイトルを重ねる |
| 中 | 左に写真（正方形）、右の推し色の塗りに、推しの名前（推しなしの予定は種類）・タイトル・残り日数・日付（`10月18日(日)`） |

- 残り日数はカウントダウンと同じ（「あと N 日」、当日は「今日！」、終わった予定は「N 日前」）。毎年くり返す予定は次の回の日付と日数
- 写真の上の文字は、黒の暗幕（不透明度 0.6。白い写真の上でも白い文字が 4.5:1 以上）の上に白で出す
- 写真の無い推しと推しなしの予定は、写真の場所を、予定の詳細で写真が無いときと同じ模様にする
- 読み上げは「推しの名前、タイトル、あと N 日、10月18日 日曜日」
- 押すとアプリで予定の詳細を開く（[規則](../rules.md)の「アプリで開く画面」）
- 予定を選んでいない・選んだ予定が削除された・データを読み込めないときは、カウントダウンと同じ表示にする
- 残り日数の数え直しと描き直しは、[ホーム画面ウィジェット](10-home-widgets.md#共通)と同じ

## Plus でないとき

- 選んだ予定の写真（無ければ模様）と文字を薄くし、鍵の記号と「Plus で使えます」を重ねる。読み上げにも「Plus で使えます」を足す。ウィジェットの一覧の見本も同じ

## 規則

| 項目 | 規則 |
|---|---|
| ウィジェットに渡すもの | アプリが、[Plus](14-plus.md) が使えるかと期限（定期購入が使えなくなる時刻。買い切りには無い）を、アプリとウィジェットで共有する場所に書く。変わったらウィジェットを描き直す |
| ウィジェットでの判定 | 使えないと書いてあれば使えない。期限が無いか、期限の前なら使える。期限の時刻ちょうどか過ぎていたら、ウィジェットの中でストアの今の購入を確かめ直す（ストアの仕組みだけで確かめ、結果は書き戻さない） |
| 期限での切り替え | 日付が変わる時刻の数え直しに加えて、先に作っておく表示の範囲に期限があれば、期限の時刻から Plus でない表示にする。その時刻に確かめ直し、更新されていれば Plus の表示に戻す。アプリを開かなくても切り替わる |
