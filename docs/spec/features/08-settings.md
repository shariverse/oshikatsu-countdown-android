# 設定

- 推し活カウントダウン Plus：いちばん上に置く。押すと課金の画面を開く（行を出す条件は[推し活カウントダウン Plus](14-plus.md)）
- 着せ替え：Plus の行のすぐ下に、説明「背景の写真と、推しの写真の飾り」を添えて置く。押すと[背景・飾りの着せ替え](17-dress-up.md)の画面を開く。行を出す条件は Plus の行と同じ
- 表示：「終わった予定も表示する」（既定は OFF）。「ホームの下に、過ぎた予定を新しい順に出します」と添える
- 通知（[通知](09-notifications.md#設定の項目)）
- データ：「この端末の中だけに保存」と、保存先の説明
  - 「推し・写真・予定は端末の外に送りません。アプリを削除すると消えます。」
- このアプリについて
  - バージョン
  - オープンソースライセンス：「このアプリで使っているライブラリとライセンス」と添える。押すとアプリで使っているライブラリ・書体の一覧（名前・作者・バージョン・ライセンス）を開く。行を押すとライセンスの本文を出す

バージョンは `versionName` を出す。
