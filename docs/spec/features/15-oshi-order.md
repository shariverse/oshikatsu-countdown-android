# 推しの並べ替え

> [!NOTE]
> Android 版では、まだ作っていない（予定）。

推しの一覧で、推しの順番を入れ替える。いちばん上の推しを **1 位の推し** と呼ぶ。

## 並び

- 初めは登録した順。追加した推しは末尾に足す。推しを削除しても、残りの推しの並びは変えない
- [推しの一覧](06-oshi.md)・[ホーム](03-home.md)の絞り込み・[予定の追加・編集](05-event-editor.md)の推しの選択肢で、同じ並びにする。予定の追加で選んでおく先頭の推しは、1 位の推し

## 操作

推しが 2 人以上のとき、推しの一覧の「並べ替え」で並べ替えの状態にし、行をドラッグして順番を入れ替える。「この順番で確定」で戻る（「完了」だと、何が終わるのかが分かりにくいため）。順番は、入れ替えるたびに保存する。

- 並べ替えの間は、行を押しても編集を開かず、「推しを登録」も押せない
- 読み上げでは、行の操作の「上に移動」「下に移動」でも入れ替えられる
- 保存に失敗したら「保存できませんでした」を出し、並びを元に戻す
