# 予定の詳細

- 推しの写真（無ければ推し色の斜めの縞）を上に敷き、中身のカードを重ねる
- 種類・推しの名前（推しなしの予定は「推しなし」）・タイトル
- 「開演まで」（時刻が無ければ「当日まで」。[規則](../rules.md)の「開始の時刻の呼び名」）と、残りの日数（大きく）・時:分:秒（1 秒ごとに進む）。当日でも、開始の時刻の前は数え続ける
- 当日の開始の時刻を過ぎたら（時刻が無ければ、当日になったら）「今日は当日！」「楽しんできてね」、終わった予定は「終わった予定」「N 日前」
- 進み具合のバー（[規則](../rules.md)の「進み具合」）。「登録 9/2」「76% 経過」「当日 10/18」。割合は整数に四捨五入する
- 「日時」（「10月18日(日) 開演 17:00」。時刻が無ければ日付だけ）・「会場・場所」（入れてあるときだけ）・「くり返し」（毎年くり返す予定だけ。「毎年この日を数えます」）
- 残り・進み具合・日時の見せ方（「あと N 日」と時間・分・秒のタイル、当日の「今日！」、進み具合のバーのハート）は、[残り時間のタイル](19-countdown-tiles.md)
- 上のボタン：戻る、ピン留めの切り替え（「ピン留めする」/「ピン留めを外す」）、画像でシェア（[シェア](13-share.md)）、編集、その他（記号だけで出し、読み上げでは「その他の操作」。中に「予定を削除」）
- 削除の確認のダイアログは「この予定を削除しますか？」「「（タイトル）」を削除します。元に戻せません。」に「削除」「キャンセル」
- 開いている予定が削除されたとき（この画面での削除、推しの削除）と、予定を読めないときは、前の画面に戻る

写真の範囲は、丸のアバターと同じ正方形を使う（[写真の調整](07-photo-crop.md#表示)）。
写真の調整はまだ作っていないので、今は取り込んだ写真の中央を基準に切り取って出す。
