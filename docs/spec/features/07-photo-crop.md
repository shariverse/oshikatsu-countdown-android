# 写真の調整

> [!NOTE]
> Android 版では、まだ作っていない（予定）。

推しの登録・編集で写真を選んだら、そのまま取り込まずに調整の画面を出し、丸の枠に写す範囲を拡大・縮小・移動・回転で決めてから取り込む。

## 流れ

1. 推しの登録・編集（初回の導線の推しの登録も同じ）で「写真を選ぶ／写真を変える」から写真を選ぶ
2. 写真を読めたら調整の画面を全画面で出す（タブレットも全画面）
3. 「完了」で丸のプレビューを切り抜いた見た目にする。取り込むのは推しを保存したとき
4. 「やめる」では何も変えない（前の写真・プレビュー・保存する内容のまま）

## 調整の画面

- 黒い地に写真を置き、丸の枠の外を暗くする。上に「やめる」「移動と拡大・縮小」「完了」
- 操作: ピンチで拡大・縮小、ドラッグで移動、2 本指のひねりで自由な角度の回転。3 つを同時に効かせ、拡大と回転は枠の中心を軸にする
- 補正: 操作の途中は枠の隅が一時的に空いてもよい。指を離したら（ジェスチャーが中断されたときも）、枠の隅が空かない範囲に寄せる。動きを減らす設定のときはアニメーションしない
  - 枠を覆う最小の拡大率は回転角で変わる: |cos θ| + |sin θ|（0°・90° で 1、45° で √2。1 は回転なしで写真の短い辺が枠にぴったり収まる大きさ）
  - 移動できる範囲は、枠の正方形を写真の上に戻したときの外接矩形が写真からはみ出さない範囲
- 拡大の上限: 切り抜く範囲の一辺が元の写真の **360px** を下回らない倍率まで（短い辺が 360px より小さい写真は、枠を覆う大きさより拡大できない）
- 枠の一辺: 写真を置く範囲の短い辺から左右 16 ずつ引いた長さ。上限 560（タブレットで広がりすぎないように）。単位は iOS は pt、Android は dp
- 読み上げ・ジェスチャーを使えない人向け: 写真を 1 つの要素（「調整中の写真」。値は拡大率と回転の角度）にし、上下のスワイプで拡大・縮小（1.25 倍ずつ）、カスタムアクションで「左に回す」「右に回す」（5° ずつ）「元に戻す」。位置を動かす操作は無い
- 大きな文字で上のバーが 1 行に収まらないときは、見出しをボタンの下に回し、それでも収まらなければボタンの文字を折り返す

## 取り込み

- **正方形に切り抜いた画像だけを保存する**。範囲（拡大率・位置・回転）は保存しない
- 一辺は min(切り抜く範囲の画素の一辺, **1440px**)。小さい写真は拡大しない
- 写真の向き（EXIF の Orientation）を画素に反映してから切り抜く。JPEG の画質 0.85、位置情報などのメタデータは残さない

## 表示

- 丸のアバター（ホームの行・推しの一覧など）は、正方形の画像をそのまま丸く出す
- 予定の詳細の横長の写真は、**同じ正方形を使う**。中央を基準に横長に切り取るので、正方形の中央の帯が写る
- ウィジェットには写真を出さない

## 調整し直し

- この機能より前に登録した写真は、今の見え方（中央基準）のまま残す。勝手に切り抜き直さない
- 写真があるときは「位置を調整」で調整の画面を開き直せる
  - 保存してある写真: 切り抜いた後の画像から開くので、**さらに狭める調整だけ**になる。範囲を広げたいときは写真を選び直す。何も変えずに「完了」したら差し替えない（JPEG を書き直して画質を落とさない）
  - 保存する前に選んだばかりの写真: 元の写真と前の範囲から開き直す（前より広げ直すこともできる。「元に戻す」は前の範囲に戻る）
- 写真の差し替え・「写真を外す」・推しの削除で、使わなくなった写真のファイルを消す

## 作らないもの

- 元の写真と範囲を保存して何度でもやり直せる方式
- 丸と詳細で別々に範囲を決める調整
- 取り込む画像の解像度・画質を選ぶ機能、ウィジェットに写真を出すこと
- 権限の追加、通信

採らなかった案の理由と、大きな写真の読み込み方などの実装の参考は [写真の調整の補足](https://github.com/shariverse/app-specs/blob/3fcc2bd96ab528c3993e1c314646ce69678cc4bc/oshikatsu-countdown/notes/photo-crop.md)。
