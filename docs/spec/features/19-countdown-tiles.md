# 残り時間のタイル

> [!NOTE]
> Android 版では、まだ作っていない（予定）。

[予定の詳細](04-event-detail.md)の、残り・進み具合・日時の見せ方。無料の機能。

何を数えるか、いつ当日・終わった予定になるか（[規則](../rules.md)の「詳細の残り」「進み具合」）と、今ある文言は変えない。変えるのは見せ方だけ。

## 残り

- 開始の前は、残りの見出し（「開演まで」など）と「あと N 日」を出す。N は大きく、推し色の文字にする
  - N は、残りを 24 時間ごとに区切った日数（[規則](../rules.md)の「詳細の残り」）。下のタイルと合わせて残りになる。暦の日数ではないので、前日でも残りが 24 時間を切ったら「あと 0 日」
- その下に、残りの時間・分・秒のタイルを 3 つ、同じ幅で横に並べる（1 秒ごとに進む）
  - タイルは、2 桁にそろえた数字（「07」）と、その下の単位（「時間」「分」「秒」）
  - 秒のタイルだけ、枠と数字を推し色にする
  - 単位は、数で形が変わらない短い書き方にする（英語は「hr」「min」「sec」）
- 開始の時刻が無い予定は、開催日の 0:00 までを同じ形で数える
- 当日の、開始の時刻の前は、「あと N 日」の代わりに「今日！」を大きく推し色で出し、きらめきの印を添える。残りの見出しは、リボンの札（アクセントの地で、右端に切れ込み）にする。タイルは、開始までの残りを数え続ける
- 当日の開始の時刻を過ぎたら（時刻が無ければ、当日になったら）、「今日は当日！」を大きく推し色で出してきらめきの印を添え、その下に「楽しんできてね」。タイルは出さない
- 終わった予定は「終わった予定」「N 日前」。タイルは出さない
- きらめきの印は大小 2 つ。大きいほうは推し色、小さいほうはアクセントの色（brand）

## 進み具合

- バーを太くし、塗りの先端にハートの印（推し色。カードの地の色で縁取る）を置く
- ハートは、塗りの先端を中心に置く。0% と 100% では、バーの端から半分はみ出す
- 両端と中央のラベル（「登録 9/2」「76% 経過」「当日 10/18」）は変えない。「76% 経過」は本文の色にする

## 日時・会場・くり返し

- 「日時」「会場・場所」「くり返し」を、1 つの札にまとめる。行は、記号・項目名・値を横に並べ、行の間に区切り線を引く。項目名の幅は、いちばん長い項目名にそろえる
- 出す行（会場は入れてあるときだけ、くり返しは毎年くり返す予定だけ）と文言は変えない

## 配色

- タイルと札の地は surfaceContainer（入力欄の地）、枠と区切り線は surfaceContainerHigh
- 秒のタイルの枠と数字は、入力欄の地の上の推し色の文字の色（[推し色](../design/oshi-colors.md#地の上の文字に使うとき)）
- リボンの札は brand の地に onBrand の文字

## 文字を大きくしたとき

- 見出しと「あと N 日」（当日はリボンの札と「今日！」）が 1 行に入りきらないときは、2 段にする
- 端末の文字の大きさをアクセシビリティの大きさにしているときは、タイルを縦に積んで数字と単位を横に並べ、日時などの行は項目名の下に値を置く

## 読み上げ

- 見出し・日数・タイルをまとめて、「開演まで、残り 3日 7時間 5分」のように 1 つで読む。秒は読まない（1 秒ごとに読み上げ直さない）
- 当日の、開始の時刻の前は、先頭に「今日！」を付ける（「今日！、開演まで、残り 41分」）
- 日時などの行は、「日時、10月18日(日) 開演 17:00」のように 1 行を 1 つで読む
- きらめきの印・リボンの形・ハートの印は読み上げない
