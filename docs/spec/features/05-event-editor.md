# 予定の追加・編集

閉じるボタン・見出し（「予定を追加」「予定を編集」）・「保存」。

| 項目 | 内容 |
|---|---|
| 推し | 推しごとの選択肢（[規則](../rules.md)の「推しの並び」の順）と「推しなし」。追加では先頭の推しを選んでおく（推しがいなければ「推しなし」） |
| 種類 | ライブ・誕生日・発売日・配信・その他。追加ではライブを選んでおく。誕生日を選ぶと「毎年くり返す」を ON、ほかの種類を選ぶと OFF（あとから切り替えられる） |
| タイトル | 必須。40 文字まで。入力の例は「例：5th LIVE 東京公演」 |
| 日付 | 追加では今日 |
| 開始時刻 | 任意。24 時間表記。決めていないときは「未定」と出す。初めて選ぶときは 18:00 から。消すボタンで時刻なしに戻す |
| 会場・場所 | 任意。40 文字まで |
| 毎年くり返す | 誕生日・記念日向け。「誕生日や記念日は、過ぎたら翌年の同じ日を数えます」と添える |

- タイトルが空白だけのときは、保存できない（[規則](../rules.md)の「文字数」）
- 編集で保存しても、ピン留めと登録した時刻は変えない。追加した予定はピン留めしない
- 予定の通知の項目は置かない（[通知](09-notifications.md)は設定でアプリ全体に対して切り替える）

全画面のダイアログ（M3）。日付は M3 の `DatePicker`、開始時刻は M3 の `TimePicker`、推しと種類は `FilterChip`。「推しなし」は推しの選択肢の後ろに置く。
