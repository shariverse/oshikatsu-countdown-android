# 当日のライブアクティビティ

> [!NOTE]
> Android 版では、まだ作っていない（予定）。

開始の時刻がある予定の当日に、開始までのカウントダウンを端末の常に見える場所に出す。通信もプッシュも使わない。

Android でどの形にするか（進行中の通知など）は、Android 版を作るときに決める。下の中身と規則は iOS 版のもの。

## 出す予定と時間

- 出す予定: 開始の時刻がある予定だけ。時刻の無い予定（誕生日など）には出さない
- 出す時間: 開始の 3 時間前から、開始の 1 時間後まで。同じ時間帯に複数あれば、それぞれ出す

## 中身

- 推し色の塗りに白い文字（カウントダウンのウィジェットと同じ）。推しの名前（推しなしの予定は種類）・タイトル・開始の時刻（`開演 17:00`）と、残りの見出し（`開演まで`）と時:分:秒（1 秒ごとに進む）。呼び名は種類で変わる（[規則](../rules.md)の「開始の時刻の呼び名」）
- 開始の時刻になったら、残りの見出しと時:分:秒の代わりに「今日は当日！」を出す（アプリを開かなくても替わる）
- 押すと、アプリでその予定の詳細を開く（[規則](../rules.md)の「アプリで開く画面」）

## 規則

| 項目 | 規則 |
|---|---|
| 時間帯 | 開始の時刻（書いた日付・時刻を端末のタイムゾーンで読む）の 3 時間前（ちょうどを含む）から 1 時間後（ちょうどは含まない）まで。開始が 0 時台なら前の日の夜から出す。毎年くり返す予定はその回の日付で数え、夜遅くの開始で時間帯が日付をまたいでも、前の回の時間帯を出し続ける |
| 置き直し | 推し・予定を保存・削除したとき、日付・時刻・タイムゾーンが変わったとき、アプリが前面に来たときに置き直す。削除した・時刻を変えた・時間帯を過ぎた予定のものは終える。中身（タイトル・推しなど）が変わったものは、終えてから新しい中身で出し直す（中身が同じなら出し直さない） |
