# 推し活カウントダウン Plus

> [!NOTE]
> Android 版では、まだ作っていない（予定）。

有料の機能。推しの写真で見た目を飾る機能を解放する。

Android でのストアの商品の作り方、課金画面の部品、「購入を復元」を置くか、利用規約に何を開くか、画面の文言の「サブスクリプション」を Google Play の言い方に合わせるかは、Android 版を作るときに決める。

## 解放するもの

- [推しの写真ウィジェット](16-photo-widget.md): 予定の推しの写真を背景にしたカウントダウンのウィジェット
- [背景・飾りの着せ替え](17-dress-up.md): アプリの背景と飾りを、推しの写真で着せ替える

今ある無料の機能（数える・ウィジェット・通知・ロック画面・当日の表示・シェア）は、有料に移さない。

## 売り方と価格

| 商品 | 価格（日本・税込み） | 内容 |
|---|---|---|
| 月額 | 280 円 | 自動で更新する定期購入 |
| 年額 | 1,980 円 | 自動で更新する定期購入。1 週間の無料のお試しつき（年額だけ） |
| 買い切り | 4,800 円 | 1 回の購入でずっと使える。今後足す Plus の機能も含む |

- Plus が使えるのは、定期購入が有効か、買い切りを買ったとき（下の「Plus が使えるかの判定」）
- 解約・期限切れで、解放した機能を Plus でない表示に戻す。選んだ画像や設定は消さずに残す（また入ったら戻る）
- 課金はストアの仕組みだけで行い、自前のサーバー・解析は使わない（通信しない方針はそのまま。購入の処理はストアが行う）
- アカウントが無いので、iOS と Android の購入は共有しない
- 解放する機能は、続けて価値を出せるよう、テーマや飾りを定期的に足していく

## Plus が使えるかの判定

| 項目 | 規則 |
|---|---|
| 定期購入 | 月額か年額が期限の前なら使える。期限の時刻ちょうどから使えない |
| 猶予期間 | 期限を過ぎても、請求に失敗したときの猶予期間の終わりの前なら使える |
| 買い切り | 期限なしで使える。定期購入が切れても、買い切りがあれば使える |
| 返金・取り消し | 返金・取り消しになった購入は数えない（買い切りも）。ほかに使える購入があれば使える |
| 検証 | ストアの仕組みが端末の中で検証できた購入だけを数える（アプリは通信しない） |
| 判定し直すとき | 起動したとき、アプリが前面に来たとき（開いている間に期限を過ぎたとき）、ストアから購入の更新が届いたとき（ほかの端末での購入・更新・返金・承認待ちの承認）、購入と購入の復元のあと |
| 起動の直後 | ストアから読み終わるまでは、前に決めた結果を使う（起動の直後に見た目が切り替わらないように） |
| ウィジェットに渡すもの | 使えるかと、使えなくなる日時（定期購入の期限と猶予期間の終わりの遅いほう。買い切りは無し）。どちらかが変わったら、ウィジェットを描き直す。ウィジェットの側の判定は[推しの写真ウィジェット](16-photo-widget.md) |

## 課金画面

題は「推し活カウントダウン Plus」。どの入口からも同じ画面を重ねて開き、「閉じる」で元の画面に戻る。上から順に並べる。

1. 見出し: 「推し活カウントダウン Plus」「推しの写真で、ホーム画面とアプリをもっと自分らしく。」と、下の機能の一覧（記号と文。画像の素材は使わない）、「数える・ウィジェット・通知などの今ある機能は、これまでどおり無料で使えます」
2. 定期購入（月額・年額）
3. 買い切り: 見出し「買い切り」と商品、「一度の購入で、今後足す Plus の機能もずっと使えます」
4. 「購入を復元」「利用規約」「プライバシーポリシー」

| 機能 | 説明 |
|---|---|
| 「推しの写真ウィジェット」 | 「ホーム画面に、推しの写真とカウントダウンを置けます」 |
| 「背景と飾りの着せ替え」 | 「アプリの背景や飾りを、推しの写真で着せ替えられます」 |

- Plus が使える人には、見出しに「Plus をお使いいただけます」を出す（商品はそのまま並べる）

## 購入の結果と復元

| 結果 | 出すもの |
|---|---|
| 購入できた | 何も出さず、判定し直す |
| 承認を待っている（保護者の承認など） | 「購入の承認を待っています」「承認されると、Plus が使えるようになります。」。承認されたら、ストアからの更新で使えるようになる |
| 自分で取り消した | 何も出さない |
| 購入に失敗した | 「購入できませんでした」「時間をおいて、もう一度お試しください。」 |
| 復元に失敗した | 「購入を復元できませんでした」「時間をおいて、もう一度お試しください。」 |

- 知らせはダイアログで出し、「閉じる」で閉じる
- 「購入を復元」は、ストアの購入を読み直して判定し直す。定期購入と買い切りの両方に効く。復元している間は押せない。失敗のほかは何も出さない

## 利用規約とプライバシーポリシー

- アプリから出ずに、アプリの中にブラウザの画面を重ねて開く。閉じると課金画面に戻る（購入の途中でアプリから離れないように）
- ページを読み込むのはブラウザで、アプリは通信の中身や閲覧の情報に触れない。アプリが自分でページを読み込む部品は使わない（[方針](../product.md)の「通信しない」）
- プライバシーポリシーは、ストアに登録するプライバシーポリシーと同じページを開く

## 定期購入中に買い切りを買う人への案内

買い切りを買っても、定期購入は自動で止まらない（請求が続く）ので、2 回伝える。

- 購入前: 自動で更新される定期購入がある間は、買い切りのそばに「サブスクリプション中に買い切りを購入しても、サブスクリプションは自動で止まりません。購入後に、ご自身で解約してください。」と出す
- 購入後: 自動で更新される定期購入があるまま買い切りを買い終えたら、ダイアログで「サブスクリプションの解約をお忘れなく」「買い切りを購入しても、サブスクリプションは自動で止まりません。続けて請求されないよう、ご自身で解約してください。」を出す。「サブスクリプションを管理」でストアの定期購入の管理を開き、「閉じる」で閉じる
- 数えるのは、自動で更新される、今使える定期購入（猶予期間中も含む）。解約済み（期限までは使えるが更新されない）・期限切れ・返金された定期購入は数えない。更新されるかが分からないときは、案内を出す

## 入口

- [設定](08-settings.md)のいちばん上に「推し活カウントダウン Plus」の行を置き、押すと課金画面を開く。説明は「推しの写真ウィジェットと、背景と飾りの着せ替え」。Plus が使える人には「Plus をお使いいただけます」
- Plus でない人が[推しの写真ウィジェット](16-photo-widget.md)を押したときと、[着せ替え](17-dress-up.md)の画面の「Plus で使う」を押したときも、課金画面を開く
