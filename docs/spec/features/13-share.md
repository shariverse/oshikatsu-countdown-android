# シェア

> [!NOTE]
> Android 版では、まだ作っていない（予定）。

予定の「あと○日」を正方形のカードの画像にして、OS の共有の画面で渡す。無料の機能（[Plus](14-plus.md) に含めない）。画像は端末の中で作り、通信しない。

## 入口と流れ

1. [予定の詳細](04-event-detail.md)の上のボタン「画像でシェア」を押す。入口はここだけ（ホームの行・ウィジェット・ロック画面には置かない）
2. プレビューの画面（題は「画像でシェア」）を重ねて開く。渡す画像そのものを縮めて見本に出し、その下の「載せる項目」で切り替える
3. 「シェアする」で OS の共有の画面を開く。渡すのは画像だけで、文やリンクは添えない。どこに渡すかは、利用者が共有の画面で選ぶ
4. 「閉じる」で予定の詳細に戻る。予定が消えたとき、ウィジェット・通知などから別の画面を開くときも閉じる

- 切り替えを変えたとき・日付が変わったときは、画像を作り直す。作り終えるまで「シェアする」は押せない
- 画像を作れなかったときは、見本の場所に「画像を作れませんでした」を出す（「シェアする」は押せないまま）

## カード

- 正方形だけ。1080 × 1080px の PNG。縦長などほかの形は作らない
- 文字の大きさの設定と端末の外観（ライト / ダーク）では変えない。同じ中身なら同じ画像になる
- 上に推しの写真、下に推し色の塗りを、1 枚の角の丸いカードにつなぎ、画面の地と同じ地の上に置く
- 文字（予定名・日付・会場・日数）は推し色の塗りの上にだけ白で置き、写真の上には重ねない。予定名は 2 行まで
- [推し色](../design/oshi-colors.md)の役割は変えない（塗り・写真が無いときの模様の色）
- カードの配色（ライトとダークのどちらで描くか）は、Android 版を作るときに決める

## 載せる項目

| 項目 | 載せるか | 切り替え |
|---|---|---|
| 予定名・日付・日数 | いつも | なし |
| 推しの写真 | 既定で載せる | 「推しの写真を載せる」。写真の無い推し・推しなしの予定では出さない |
| 会場 | 既定で載せない | 「会場を載せる」。会場の無い予定では出さない |
| 透かし | いつも | なし（消す・小さくする選択肢は作らない） |
| 推しの名前 | 載せない | なし |

- 写真を載せないとき・写真が無いとき・読めないときは、写真の場所を推し色の模様にする（予定の詳細の写真が無いときと同じ模様）
- 写真の切り替えを出すときは、下に「写真を載せないときは、推し色の模様にします」と添える
- 切り替えを 1 つも出せない予定では、「載せる項目」の欄ごと出さない

## 日数の見せ方

[規則](../rules.md)の「残り日数」で数える。日付は年と曜日まで出す（`2026年10月18日(日)`）。

| 予定 | カードの例 | 決まり |
|---|---|---|
| 先の予定 | `あと 3 日` | |
| 当日 | `今日！ 開演 17:00` | 開始の時刻の前でも後でも「今日！」（予定の詳細と違い、日の単位で見せる）。開始の時刻が無ければ「今日！」だけ |
| 終わった予定 | `3 日前` | 終わった予定もシェアできる |
| 毎年くり返す予定 | 次の回の日付と `あと N 日` | くり返しの印や回数は載せない |

## 透かし

- アプリの名前「推し活カウントダウン」を、カードの外の地に右寄せで小さく入れる。文字や写真には重ねない

## 読み上げと許可

- 見本は画像 1 つとして読み上げ、予定名・日付・日数・会場（載せるときだけ）を読む。透かしは読まない
- 写真を読む許可は求めない
