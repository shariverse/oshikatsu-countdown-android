# 推し活のモチーフ

> [!NOTE]
> Android 版では、まだ作っていない（予定）。

ホームと推しの一覧に、推し活のモチーフ（チケット・チェキ・缶バッジ・リボン）を足す。無料で、全員に出す。

- 配色・書体・角の丸み・地の模様・カードの縁、[推し色](../design/oshi-colors.md)の値と役割、[規則](../rules.md)、今ある文言は変えない
- モチーフは図形と記号で描き、画像の素材は使わない。飾り（切り欠き・ミシン目・チェキ・ツヤ・印）は読み上げず、押せる範囲・並び順を変えない
- アプリの画面だけに足す。[ホーム画面ウィジェット](10-home-widgets.md)と[シェア](13-share.md)のカードの見た目は変えない

Android での寸法・部品は、Android 版を作るときに決める。下の寸法は iOS 版のもの。

## モチーフ

| モチーフ | 形 |
|---|---|
| チケット | 角の丸いカードの左右の辺に、半円の切り欠きを入れる。切り欠きを結ぶ点線（ミシン目）で、本体と半券に分ける。カードの縁の線は、切り欠きに沿わせる |
| チェキ | 白い枠に写真を入れ、下の余白を広く取る。右下に推し色の小さなハートを置き、薄い影を落として、少し傾ける。写真が無ければ、写真の場所を模様で埋めて、名前の頭文字を置く |
| 缶バッジ | [アバター](06-oshi.md#アバター)を推し色の輪で縁取り、左上にツヤを置いて、薄い影を落とす。写真の無いアバター（推し色の丸と頭文字）にも輪を付ける |
| リボンの札 | アクセントの色（brand）の地に、その上の文字の色（onBrand）で書く。右の端に、三角の切れ込みを入れる |
| 「今日！」の札 | [推し色](../design/oshi-colors.md#地の上の文字に使うとき)を地の上の文字に使うときの色の地に、カードの地の色（surface）で「今日！」と書く。前に、きらめきの印を置く |

- チェキの大きさは、端末の文字の大きさの設定に追従させない
- 缶バッジの輪の色は、推し色を地の上の文字に使うときの色
- リボンの札と「今日！」の札の文字は、札の地の上で 4.5:1 以上にする

## ホーム

[ホーム](03-home.md)の先頭の予定のカード・行・見出しを、次のようにする。絞り込み・並び・タブは変えない。

- **先頭の予定のカード**: チケットの形にする。推し色の塗りと白い文字はそのまま
  - 本体: 札を 2 つ（「ピン留め」か「いちばん近い予定」。「ピン留め」には前にピンの印を置く。その隣に予定の種類）、推しの名前（推しなしの予定は出さない）、タイトル、「あと N 日」（当日は「今日！」）
  - 写真のある推しの予定は、本体の右に、推しの写真をチェキで載せる。写真の無い推しの予定・推しなしの予定では載せない
  - 半券: 日付（`10.18 SUN`）、開始の時刻（`開演 17:00`。時刻がある予定だけ）、会場（入っている予定だけ。前に場所の印を置く）
  - 1 行に収まらないときは、推しの名前・会場を下の行に回す
  - 読み上げは、札・予定の種類・推しの名前・タイトル・残り日数・日付・開始の時刻・会場の順
- **これからの予定・終わった予定の行**: アバターを缶バッジにする。当日は、残り日数の「今日！」を「今日！」の札で出す。残り日数の数字と色は変えない
- **見出し**（「これからの予定」「終わった予定」）: リボンの札にする

## 推しの一覧

[推しの一覧](06-oshi.md#一覧)を、次のようにする。

- **1 位の推し**（[推しの並べ替え](15-oshi-order.md)）は、大きいカードで出す。チェキの写真、リボンの札「最推し！」（前に王冠の印を置く。順位の数字は出さない）と「テーマカラー」、名前、次の予定のタイトル、「あと N 日」（当日は「今日！」の札）、予定の件数（「予定 3 件」）
- **2 位からの推し**は、行で出す。缶バッジのアバター、名前、「次の予定のタイトル · 日付」、右に残り日数（「N 日」を推し色で。当日は「今日！」の札）。タイトルが長くて 1 行に収まらないときは、日付を残してタイトルを切り詰める
- **次の予定**は、その推しの当日とこれからの予定のうち、いちばん近いもの。同じ日の予定は、[規則](../rules.md)の「同じ日の並び」の先頭。ピン留めは見ない
- これからの予定が無い推しは、次の予定と残り日数を出さず、予定の件数を出す
- 日付が変わったら、次の予定と残り日数を数え直す（ホームと同じく、1 分おきに日付を確かめる）
- 読み上げは、1 位の推しのカードが「最推し！、テーマカラー、（名前）、（次の予定のタイトル）、（日付）、（残り日数）、予定 3 件」、行が「（名前）、（次の予定のタイトル）、（日付）、（残り日数）」。これからの予定が無い推しは、次の予定・日付・残り日数を読まず、行は「（名前）、予定 3 件」と読む
- [並べ替え](15-oshi-order.md#操作)の間は、カードをやめて、どの推しも同じ形の行（順位・缶バッジのアバター・名前・予定の件数）にする。順位の数字と案内の文言は変えない（「最推し！」は、1 位の推しのカードにだけ出す）
