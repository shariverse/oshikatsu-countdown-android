# ホーム

- 見出し「推し活カウントダウン」
- 推しの絞り込み（「すべて」と推しごとの選択肢。[規則](../rules.md)の「推しの並び」の順）。推しを選ぶと、その推しの予定だけを出す（先頭の予定もその中から選ぶ）。選んでいた推しが削除されたら「すべて」に戻す。推しが 1 人もいなければ出さない
- **先頭の予定のカード**：推し色の塗りに白い文字。ピン留めした予定（終わっていなければ）、無ければいちばん近い予定。「ピン留め」/「いちばん近い予定」、推しの名前（推しなしの予定は出さない）、タイトル、「あと N 日」（当日は「今日！」）、日付（`10.18 SUN`）、開始の時刻（`開演 17:00`。時刻がある予定だけ）
- **これからの予定**：当日とこれからの予定を近い順（先頭の予定のカードに出した予定も出す）。行は推しの[アバター](06-oshi.md#アバター)、タイトル、「日付 · 推しの名前」（毎年くり返す予定は、推しの名前の代わりに「毎年」。推しなしの予定は「推しなし」）、残り日数（「N 日」。当日は「今日！」）を推し色で
- **終わった予定**：設定で ON のときだけ。新しい順に「N 日前」
- カードと行は、押すと[予定の詳細](04-event-detail.md)を開く
- 先頭の予定のカード・行・見出しの形と、カードに足す項目（予定の種類・会場・推しの写真）は[推し活のモチーフ](18-oshikatsu-motifs.md#ホーム)
- 右下の「予定を追加」
- 予定が 1 件も無いときは「まだ予定がありません」「ライブ・誕生日・発売日を登録すると、その日まであと何日かを数えます。」と「予定を追加」
- 絞り込んだ推しに予定が 1 件も無いときは「この推しの予定はまだありません」
- これからの予定が無いとき（終わった予定しか無いとき）は「これからの予定はありません」
- ただし、絞り込んだ推しの予定がすべて終わっていて、終わった予定を表示していないときは「この推しの予定はまだありません」

並び・残り日数・ピン留めの決まりは [規則](../rules.md)。

推しの絞り込みは M3 の `FilterChip`。
