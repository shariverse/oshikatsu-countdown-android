# 規則

画面をまたいで効く決まり。機能だけの規則は、それぞれの機能のファイルに書く。

| 項目 | 規則 |
|---|---|
| 日付と時刻の持ち方 | 予定の日付と開始の時刻は、書いたまま持つ（タイムゾーンを持たない）。端末のタイムゾーンを変えたら、その土地の同じ日付・時刻として数える |
| 残り日数 | 端末のタイムゾーンでの暦の日数。当日は「今日！」 |
| 詳細の残り | 開始の時刻（無ければ開催日の 0:00）までの時間を、日（24 時間単位）と時:分:秒で |
| 毎年くり返す予定 | 登録した日付がまだ来ていなければその日、過ぎていれば今年か来年の同じ日（当日を含む）を数える。終わった予定にはならない。2/29 は平年には 2/28 |
| 終わった予定 | くり返さない予定で、開催日を過ぎたもの |
| 同じ日の並び | 時刻の無い予定（終日）、時刻の早い順、登録した順。毎年くり返す予定は、次の回の日付で並べる。終わった予定は、同じ日なら時刻の遅い順（終日は最後） |
| 推しの並び | [推しの並べ替え](features/15-oshi-order.md)で決めた順（並べ替えるまでは登録した順）。推しの一覧・ホームの絞り込み・予定の追加と編集の推しの選択肢で同じ並びにする |
| ピン留め | 1 件だけ。別の予定をピン留めすると前のピン留めは外れる |
| 日付が変わったとき | ホームは 1 分おきに日付を確かめ、変わったら数え直す |
| 開始の時刻の呼び名 | 種類で変える。ライブは「開演」、発売日は「発売」、配信は「配信開始」、誕生日・その他は「開始」。開始の時刻は「開演 17:00」、残りの見出しは「開演まで」のように出す（開始の時刻が無い予定の見出しは「当日まで」）。ホーム・予定の詳細・通知・ライブアクティビティで共通 |
| 日付と時刻の書き方 | 一覧・予定の詳細・通知・ウィジェットの日付は「10月18日(日)」、ホームの先頭の予定のカードは「10.18 SUN」（曜日は英語の大文字）、進み具合のバーの両端は「10/18」。時刻は端末の設定にかかわらず 24 時間表記で、時の頭に 0 を付けない（「17:00」「9:30」） |
| 文字数 | 見た目の 1 文字（書記素クラスタ）で数える。連続する空白（改行・全角の空白を含む）は 1 つに潰し、前後の空白は落とす。必須の欄は、空白だけなら空とみなし、保存できない |
| 上限を超える入力 | 上限を超える分は、入力のたびに切る |
| 保存・削除の途中 | 画面を閉じない（閉じる・戻るを押せない） |
| 保存・削除の失敗 | 「保存できませんでした」「削除できませんでした」を出す。入力は残し、もう一度押せる。ピン留めの切り替えの失敗も「保存できませんでした」を出す |
| 進み具合 | 登録した時刻（毎年くり返す予定は、前の回の開始のほうが後ならその時刻）から開始までの時間のうち、過ぎた割合。当日の開始の時刻を過ぎたあとと、終わった予定は 100%。起点が開始より後で求められないときは出さない。予定の詳細とロック画面のカウントダウンで使う |
| 推しの表示名 | 推しなしの予定（結び付いた推しが見つからない予定を含む）では、ウィジェット・通知・ライブアクティビティは、推しの名前の代わりに種類を出す。アプリの画面（ホームの行・予定の詳細）と、ウィジェットの予定を選ぶ一覧は「推しなし」を出す。ホームの行のアバターには、タイトルの頭文字を出す |
| 推しなしの予定の色 | 推し色の代わりに、[推し色](design/oshi-colors.md)のブラックを使う（どの推し色とも紛れない無彩色）。塗り・印・残り日数の文字・写真が無いときの模様で共通 |
| アプリで開く画面 | ウィジェット・通知などから予定の詳細や予定の追加を開くときは、ホームのタブに切り替え、最初の画面まで戻してから開く。初回の導線の途中なら開かない（導線を終えたあとにも開かない） |
| 開いていた入力の画面 | ウィジェットから画面を開くときは、ホームのタブに積んでいた画面を、入力の途中でも確かめずに閉じる。ほかのタブに積んでいた画面は残す |
