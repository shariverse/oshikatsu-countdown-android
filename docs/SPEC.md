# 推し活カウントダウン Android 版 仕様

推し活の予定（推しのライブ・誕生日・発売日など）を登録し、その日まであと何日かを数えるアプリ。
画面デザインの正はデザインキャンバス「推し活カウントダウン 画面デザイン」の Android の 2 枚（ホーム、ウィジェット・通知）と iOS の主要画面 4 枚。
部品と操作感は iOS の画面をコピーせず Material 3 の標準に従い、デザインから引き継ぐのは機能・文言・配色だけにする。
実装の構成は [`architecture.md`](architecture.md)。

---

## 1. 範囲

アプリ内の画面、ホーム画面ウィジェット、端末の中への保存まで。

| 機能 | 状態 |
|---|---|
| 初回の導線（推しの登録 → 最初の予定の登録） | あり |
| ホーム（推しで絞り込み、先頭の予定、これからの予定・終わった予定） | あり |
| 予定の追加・編集・削除・ピン留め | あり |
| 予定の詳細（秒単位のカウントダウン、進み具合） | あり |
| 推しの一覧・登録・編集・削除（写真・推し色） | あり |
| 設定（終わった予定の表示、データの保存先の説明、バージョン、オープンソースライセンス） | あり |
| カレンダーのタブ | なし |
| ホーム画面ウィジェット（カウントダウン・推しカウント） | あり |
| 丸いウィジェット・ロック画面ウィジェット | なし |
| ローカル通知（30 日前・7 日前・前日・当日・開演 1 時間前）、当日の進行中の通知 | なし。予定の入力欄にも通知の項目を置かない |
| 広告（リスト内バナー・ネイティブ広告・インタースティシャル・リワード） | なし。広告の枠も置かない |
| 画像でシェア、検索 | なし |
| 英語の文言 | なし（日本語だけ） |

通信しない。推し・写真・予定は端末の中（DataStore とアプリの内部ストレージ）にだけ置く。

## 2. 画面

### 2.1 初回の導線

設定の「導線を終えた」が保存されるまで、タブの代わりに出す。

1. **ステップ 1 / 2：推しの登録**（推しの登録・編集の画面）。「次へ：最初の予定を登録」で登録して次へ。上の「あとで」で登録せずに次へ
2. **ステップ 2 / 2：最初の予定**（予定の追加の画面）。登録したばかりの推しを選んでおく。「保存してはじめる」で保存してタブへ。上の「あとで」で保存せずにタブへ

2 歩目から 1 歩目には戻らない（登録した推しを同じ画面でもう一度登録させないため）。

### 2.2 タブ

ホーム・推し・設定の 3 つ。M3 の基準で、電話はナビゲーションバー、広いウィンドウはナビゲーションレール。
詳細・入力の画面を開いている間はナビゲーションを隠す。

### 2.3 ホーム

- 見出し「推し活カウントダウン」
  - iOS 版は、ホームの見出しを画面に出さない。上のバーは「予定を追加」の ＋ だけにし、先頭の予定のカードを上に詰める（タブの「ホーム」で今の場所は分かる）。
    VoiceOver が読み上げる画面の名前としては「推し活カウントダウン」を残す（[iOS の Discussion #148](https://github.com/shariverse/oshikatsu-countdown-ios/discussions/148) の Q1）
  - iOS 版の iPad の広い画面では、サイドバーの上にアプリの名前として「推し活カウントダウン」を出す（同じく Q4）
  - Android 版も見出しを出さないようにするかは、Android 側で決める。決めるまでは、Android 版は見出しを出す
- 推しの絞り込み（「すべて」と推しごとの `FilterChip`）。推しが 1 人もいなければ出さない
- **先頭の予定のカード**：推し色の塗りに白い文字。ピン留めした予定（終わっていなければ）、無ければいちばん近い予定。「ピン留め」/「いちばん近い予定」、推しの名前、タイトル、「あと N 日」、日付（`10.18 SUN`）、開始の時刻（`開演 17:00`）
- **これからの予定**：当日とこれからの予定を近い順。行は推しのアバター（写真か頭文字）、タイトル、「日付 · 推しの名前」（毎年くり返す予定は「· 毎年」）、残り日数を推し色で
- **終わった予定**：設定で ON のときだけ。新しい順に「N 日前」
- 右下の「予定を追加」
- 予定が 1 件も無いときは案内と「予定を追加」

### 2.4 予定の詳細

- 推しの写真（無ければ推し色の斜めの縞）を上に敷き、中身のカードを重ねる
- 種類・推しの名前・タイトル
- 「開演まで」（時刻が無ければ「当日まで」）と、残りの日数（大きく）・時:分:秒（1 秒ごとに進む）
- 当日の開始の時刻を過ぎたら「今日は当日！」、終わった予定は「終わった予定」「N 日前」
- 進み具合のバー：登録した日（毎年くり返す予定は前の回のほうが後ならその日）から当日まで。「登録 9/2」「76% 経過」「当日 10/18」
- 日時・会場・くり返し
- 上のボタン：戻る、ピン留めの切り替え、編集、その他（予定を削除。確認のダイアログを出す）

### 2.5 予定の追加・編集

全画面のダイアログ（M3）。閉じる・見出し・保存。

| 項目 | 内容 |
|---|---|
| 推し | 推しごとのチップと「推しなし」。追加では先頭の推しを選んでおく |
| 種類 | ライブ・誕生日・発売日・配信・その他。誕生日を選ぶと「毎年くり返す」を ON、ほかの種類を選ぶと OFF（あとから切り替えられる） |
| タイトル | 必須。40 文字まで |
| 日付 | M3 の `DatePicker`。追加では今日 |
| 開始時刻 | 任意。M3 の `TimePicker`（24 時間表記）。初めて選ぶときは 18:00 から。消すボタンで時刻なしに戻す |
| 会場・場所 | 任意。40 文字まで |
| 毎年くり返す | 誕生日・記念日向け |

### 2.6 推しの一覧と登録・編集

- 一覧：登録した順に、アバター・名前・予定の件数。押すと編集、右下の「推しを登録」で登録
- 登録・編集：写真（Photo Picker。写真を変える・外す）、名前（必須。20 文字まで）、推し色（12 色から 1 つ）、「写真と推し色はこの端末の中だけに保存されます」
- 削除（編集のときだけ）：確認のダイアログに、一緒に消える予定の件数を出す。推しと、結び付いた予定と、写真を消す

### 2.7 設定

- 終わった予定も表示する（既定は OFF）
- データの保存先の説明（端末の外に送らない、アプリを削除すると消える）
- このアプリについて
  - バージョン（`versionName`）
  - オープンソースライセンス：押すとアプリで使っているライブラリの一覧（名前・作者・バージョン・ライセンス）を開く。行を押すとライセンスの本文を出す

### 2.8 ホーム画面ウィジェット

端末のウィジェットの一覧から置く。色は端末の外観（ライト / ダーク）に合わせる。

- **カウントダウン**（2×2）：選んだ予定 1 件。推し色の塗りに白い文字で、推しの名前（推しなしの予定は種類）、タイトル、「あと N 日」。
  当日は「今日！」、終わった予定は「N 日前」。数字は桁が多い・ウィジェットが狭いときに小さくする
  - 置くときに「表示する予定を選ぶ」画面を出し、当日とこれからの予定から 1 件選ぶ。選ばずに閉じたら置かない。Android 12 以降は長押しで選び直せる
  - 押すとアプリで予定の詳細を開く
  - 選んだ予定が削除されたら「予定が見つかりません」「タップして予定を選び直す」。押すと選ぶ画面を開く
- **推しカウント**（4×2）：当日とこれからの予定を近い順に、推し色の丸・タイトル・残り日数（推し色。当日は「今日！」）。予定が無ければ「これからの予定はありません」
  - 行を押すとアプリで予定の詳細、右上の ＋ で予定の追加、見出しでアプリを開く
- アプリで開く画面はホームのタブに積む（ホームのタブは最初の画面まで戻す）。初回の導線の途中なら開かない

## 3. 規則

| 項目 | 規則 |
|---|---|
| 残り日数 | 端末のタイムゾーンでの暦の日数。当日は「今日！」 |
| 詳細の残り | 開始の時刻（無ければ開催日の 0:00）までの時間を、日（24 時間単位）と時:分:秒で |
| 毎年くり返す予定 | 登録した日付がまだ来ていなければその日、過ぎていれば今年か来年の同じ日（当日を含む）を数える。終わった予定にはならない。2/29 は平年には 2/28 |
| 終わった予定 | くり返さない予定で、開催日を過ぎたもの |
| 同じ日の並び | 時刻の無い予定（終日）、時刻の早い順、登録した順 |
| ピン留め | 1 件だけ。別の予定をピン留めすると前のピン留めは外れる |
| 日付が変わったとき | ホームは 1 分おきに日付を確かめ、変わったら数え直す。ウィジェットは 0:00 から 10 分以内と、端末の時刻・タイムゾーンを変えたときに数え直す |
| ウィジェットの描き直し | 推し・予定を保存・削除したらすぐ描き直す |
| 文字数 | 見た目の 1 文字（書記素クラスタ）で数える。連続する空白は 1 つに潰し、前後の空白は落とす |
| 写真 | 選んだ写真は長辺 1440px 以下の JPEG に縮めてアプリの内部ストレージに取り込む。差し替え・外す・推しの削除で前の写真を消す |
| 保存・削除の途中 | 画面を閉じない（閉じる・戻るを押せない） |
| 保存・削除の失敗 | 「保存できませんでした」「削除できませんでした」を Snackbar で出す。入力は残し、もう一度押せる |
| バックアップ | 自動バックアップと端末間の移行の対象にしない。機種変更では引き継がない |

## 4. デザインからの読み替え

| 項目 | デザイン | Android 版 |
|---|---|---|
| 書体 | Outfit（数字）+ Zen Kaku Gothic New | システムの既定の書体。数字は太字で桁の幅をそろえる（`tnum`。秒が進んでも横に揺れない） |
| 予定の追加 | iOS のシート（ガラス風） | M3 の全画面のダイアログ |
| 種類の選択 | iOS のセグメント | M3 の `FilterChip` |
| 推し色の選択 | 色の丸 | 同じ見た目で、ラジオボタンとして読み上げる。1 つ 48dp 以上 |
| 詳細の上のボタン | ガラス風の丸 | M3 の `FilledTonalIconButton`（地はカードの色を少し透かす） |
| ダークの外観 | デザインはライトだけ | M3 のダークの地。推し色を地の上の文字に使うときは白に 45% 寄せる（暗い推し色でも 4.5:1 を保つ） |
| ホームの検索ボタン | あり | 置かない（検索は範囲外） |
| 予定の通知の項目・ウィジェットの案内 | 予定の追加にあり | 置かない（通知は範囲外。ウィジェットは端末のウィジェットの一覧から置く） |
| ウィジェットの角 | 決まった丸み | 端末のウィジェットの角の丸み（Android 12 以降。11 では角を丸めない） |
| 推しカウントの地 | 薄い灰色（`#F3EDF1`） | カードの地（ライトは白）。推し色の文字が 4.5:1 を保てる地にする |
| 推しカウントの ＋・行 | 32dp の丸、詰めた行 | ＋ は見た目の丸を 32dp のまま、押せる範囲を M3 の 48dp にする。行の高さも 48dp |
